# 十围五攻 — 实力比驱动的行动选择

## R — 原文 (Reading)

> "故用兵之法，十则围之，五则攻之，倍则分之，敌则能战之，少则能逃之，不若则能避之。故小敌之坚，大敌之擒也。"
>
> — 孙武，《孙子兵法·谋攻篇》

---

## I — 方法论骨架 (Interpretation)

可选的动作不由意愿决定，由**实力比**决定。先把敌我力量摆到同一张表上算比值，再查表选动作：

| 实力比（我:敌） | 动作 | 逻辑 |
|---|---|---|
| ~10:1 | 围而不打 | 优势大到不必付出交战成本 |
| ~5:1 | 正面进攻 | 优势足以承受进攻损耗 |
| ~2:1 | 分割对方 | 制造局部的更大优势再打 |
| ~1:1 | 可以一战 | 胜负在操作，不在底牌 |
| 劣势 | 脱离接触 | 保存力量，换战场或等比值变化 |
| 悬殊劣势 | 彻底回避 | 接触本身就是输 |

核心禁令写在最后一句："小敌之坚，大敌之擒" — 劣势方的"死撑"不是悲壮是败因，意志力不能出现在实力比的算式里。

## A1 — 书中的应用 (Past Application)

> 注: 谋攻篇无作者亲历案例（见 `candidates/cases.md`），以下为篇中给出的**规则后果描述**。

### 情境: 小敌之坚，大敌之擒
- **问题**: 实力明显劣势，但选择坚守硬拼
- **违反方法论的做法**: 用"坚"（意志）替代查表结果（"少则能逃之"）
- **结论**: 成为强者的俘虏 — 不是虽败犹荣，是必然被擒
- **方法论含义**: 表中"逃、避"与"围、攻"地位平等，都是正确答案，不是耻辱选项

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对更强的竞争者，纠结要不要正面跟进（抢同一市场/同一资源/同一岗位）
2. 拥有明显优势，但准备用代价最高的方式碾压过去
3. 复盘一场对抗，想知道当初该打该撤

### 语言信号 (用户的话里出现这些就应激活)

- "我们打得过吗 / 刚得动吗 / 有胜算吗"
- "对方比我们强很多，但我不想认怂"
- "should we compete head-to-head / are we outgunned"

### 与相邻 skill 的区分

- 与 `victory-without-battle` 的区别: 它回答"选哪类手段"（谋/交/兵/城）；本 skill 回答"实力比允许哪种动作"。通常它在前（选层级），本 skill 在后（层级内定动作）
- 与 `know-both-sides` 的区别: 实力比的输入（敌我力量数据）来自它的审计；数据没盘清时先用它，否则比值是编的

## E — 可执行步骤 (Execution)

1. **拆解力量维度**: 列出本场对抗中真正起作用的力量维度（资金/人力/渠道/时间/授权……），排除面子和情绪
   - 完成标准: 有一张 ≤5 行的力量对比表
   - 判停条件: 若任一关键维度的对方数据是猜的，跳 know-both-sides 补齐后再回来
2. **估比值、定档位**: 对每个维度估比值，取对结果影响最大的维度定总档位（围/攻/分/战/逃/避）
   - 完成标准: 能说出"按 X 维度约 N:1，落在'某'档"
3. **执行档位动作，禁止跨档**: 特别检查劣势档 — 若结论是逃/避而用户想"坚持"，显式引用"小敌之坚，大敌之擒"给出警告
   - 完成标准: 建议动作与档位一致；若用户坚持跨档，已明确记录风险
4. **设定比值复核点**: 实力比会变，约定何时重算（融资到账/对方换帅/季度末）
   - 完成标准: 有一个具体的重算触发条件

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非对抗性决策（选技术方案、定价格）— 没有"敌我"就没有比值
- 一次性道德底线问题 — 有些事实力再悬殊也要做/不做，查表逻辑不适用
- 信息严重不足时 — 编出来的比值比没有比值更危险

### 作者在书中警告的失败模式

- **小敌之坚，大敌之擒** (ce03): 把坚持当美德，用意志对冲实力差。预警信号：论证里出现"就算输也要让他知道我们不好惹"

### 作者的盲点 / 时代局限

- 比值档位按冷兵器野战设定（10:1 才围），现代竞争中杠杆点不同（技术代差、平台效应可让 1:10 翻盘），档位间距要按领域重估
- 力量被假定为单维可比；多维力量（钱多 vs 人强 vs 快）的换算作者未给出，需要自行判断关键维度
- "逃之/避之"假定存在可退的空间；无处可退的场景（唯一市场、唯一雇主）需要先造退路再查表

### 容易混淆的邻近方法论

- "以弱胜强的经典案例" — 那些案例几乎都是先局部造出优势比（对应"倍则分之"），不是档位规则的反例，是它的应用
