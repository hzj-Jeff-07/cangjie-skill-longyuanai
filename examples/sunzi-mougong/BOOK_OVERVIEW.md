## 1. 结构 (Structural)

### 类型
方法论（战略决策论）

### 一句话主旨
胜利的上策是不经交战就使敌人屈服（"全胜"），为此要按"谋 → 交 → 兵 → 城"的成本阶梯选择手段，以敌我实力比决定打法，而这一切判断的前提是"知彼知己"。

### 骨架 (主要论点及其关系)

1. **全胜优先**: 百战百胜不算最好，"不战而屈人之兵"才是善之善者（价值标准）
2. **手段阶梯**: 伐谋 → 伐交 → 伐兵 → 攻城，按破坏成本升序排列，攻城是不得已（实现路径之一）
3. **量力用兵**: 按敌我兵力比选择围 / 攻 / 分 / 战 / 逃 / 避，弱而硬拼必被擒（实现路径之二）
4. **君将分权**: 君主遥控军队有"縻军、惑军、疑军"三患，"将能而君不御者胜"（组织保障）
5. **知彼知己**: 对敌我双方的了解程度直接决定胜负概率（认知前提）

**论点之间的关系**: 层层支撑 — 1 是价值标准，2、3 是实现它的两条方法路径，4 是组织条件，5 是全部判断的信息前提。

### 作者要解决的核心问题
在战争代价极高的前提下，如何以最小的破坏获得最完整的胜利？

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 全 / 破 | "全"指使敌方国、军、旅完整地屈服；"破"指击破对方后取胜 | 常识把"赢"当一个词，作者把"完整地赢"和"打烂了赢"分为两档，前者为上 |
| 伐谋 | 在对方的计谋、意图层面挫败它 | 不是"用计谋打仗"，而是"攻击对方的计划本身" |
| 伐交 | 瓦解、争取对方的同盟关系 | 外交在这里是攻击手段，不是和平姿态 |
| 蚁附 | 士兵像蚂蚁一样爬城强攻 | 作者用它专指将领情绪失控导致的灾难性强攻 |
| 縻军 | 君主不知前线可否进退却强令进退，束缚军队 | 现代语境即"外行遥控内行"的微观管理 |
| 知胜有五 | 可预先判断胜负的五个条件 | 胜负在开战前可由条件清单判断，而非临场发挥 |

### 核心命题 (用自己的话)

1. 竞争的最优解是让对方放弃抵抗，而不是消灭对方——破坏本身是成本
2. 手段有成本阶梯，应从破坏最小的一端开始尝试，最高破坏的手段是垫底选项
3. 实力对比决定可行动作集合：优势可围可攻，劣势只能分、守、逃、避
4. 硬拼精神不能替代实力计算，"小敌之坚，大敌之擒"
5. 决策权应交给掌握一线信息的人，远程指挥者的干预是败因
6. 胜负大概率在信息完备度上被提前决定："知彼知己，百战不殆"

### 论证链
从价值标准（全胜）出发 → 推出手段排序（伐谋阶梯）→ 用兵力比给出操作规则（十围五攻）→ 指出组织失败模式（君之三患）→ 归结到认知前提（知彼知己）。论证方式以断言 + 排比对仗为主，几乎不用具体战例，靠成本逻辑自洽。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 手段阶梯建立在冷兵器攻城成本极高（"修橹轒輼，三月而后成"）的前提上；现代竞争中"攻城"（正面对抗）的成本结构已不同，阶梯的间距甚至顺序都需要按场景重估

### 作者的立场盲点
- 全篇站在进攻方 / 强势方视角；弱势方除了"逃之、避之"，如何主动"伐谋"几乎没有展开
- 假定存在一个统一的决策者（"将"），对多方博弈、内部利益不一致的组织场景没有讨论

### 未被证明的假设
- 默认"不战而屈人之兵"始终是可得选项——现实中对手可能不可谈判、不可威慑
- "知彼"被当作可以做到的事，但对信息如何获取、被欺骗怎么办（这在《用间篇》才展开）本篇按下不表

### 最强反对意见
若所有参与者都信奉"上兵伐谋"，谋略与威慑本身会成为新的军备竞赛——全胜策略在对称博弈下可能自我失效，最终仍退化为实力对抗。
