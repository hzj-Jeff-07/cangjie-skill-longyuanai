# 知彼知己 — 决策前的信息完备度审计

## R — 原文 (Reading)

> "知彼知己者，百战不殆；不知彼而知己，一胜一负；不知彼不知己，每战必殆。"
>
> — 孙武，《孙子兵法·谋攻篇》

---

## I — 方法论骨架 (Interpretation)

重大行动前，先审计信息状态而不是直接权衡利弊。把信息分两栏：

- **知彼** — 对方/环境栏：对手的实力、意图、约束；市场的真实状况；规则的实际执行方式
- **知己** — 自己栏：我真正要什么、我的底牌和短板、我能承受的最坏结果

两栏状态对应三档结果预期：都清楚 → 大概率稳（"不殆"）；只清楚自己 → 对半开（"一胜一负"）；都不清楚 → 大概率翻车（"每战必殆"）。

方法论的锋利处在第二栏：人默认自己了解自己，所以"知己"栏几乎总是虚填的。审计的动作是逼自己把两栏写成白纸黑字，空白超过一半的栏就是下一步行动——**先补信息，而不是"再想想"**。

## A1 — 书中的应用 (Past Application)

> 注: 谋攻篇无作者亲历案例（见 `candidates/cases.md`），以下为篇中给出的**条件-结果对应**。

### 情境: 三种信息状态与三种结局
- **问题**: 同样一场仗，为什么结局可预判？
- **方法论的使用**: 作者不问士气、不问天命，只问两栏信息的完备度
- **结论**: 胜负概率在开战前已由"知"的状态决定；"知胜有五"清单第一条即"知可以战与不可以战者胜"
- **含义**: 把不可控的"胜负"转换成可控的"信息完备度"，这是本篇最强的工程化转换

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对跳槽 / 投资 / 接大项目等重大选择，反复纠结但说不清缺什么
2. 决策论证里出现"赌一把 / 感觉能行 / 先干了再说"
3. 只研究了对方（或只审视了自己），另一栏是空的而不自知

### 语言信号 (用户的话里出现这些就应激活)

- "要不要赌一把 / 感觉这个机会不错 / 先干了再说"
- "我了解过对方了，应该没问题"（知己栏空）
- "do I know enough to decide / should I take the leap"

### 与相邻 skill 的区分

- 与 `victory-without-battle` 的区别: 它假设信息已够、直接排手段阶梯；本 skill 在它之前，负责判断"信息够不够"
- 与 `strength-ratio-decision` 的区别: 它消费敌我数据算比值；本 skill 生产这些数据。数据没盘清就算比值，等于编数字

## E — 可执行步骤 (Execution)

1. **立两栏**: 明确"彼"是谁/什么（对手、雇主、市场），分别列出两栏的关键问题清单（各 3–5 条）
   - 完成标准: 两栏问题都是具体可回答的（"对方为什么开这个价"），不是抽象的（"对方怎么样"）
2. **如实标注**: 每条标注 已知✓ / 猜测? / 空白✗ — 猜测必须归为"不知"
   - 完成标准: 没有一条"应该是/大概是"被标成已知
3. **判档**: 两栏及格（✓ 过半且无关键空白）→ 进入正常决策；任一栏不及格 → 输出的不是结论而是**补信息清单**（每条空白对应一个获取动作）
   - 判停条件: 若用户拒绝补信息坚持要结论，给出结论的同时显式声明当前处于"一胜一负"或"每战必殆"档
4. **复核知己栏**: 单独追问一次"我能承受的最坏结果是什么、我为什么真的想要这个" — 这栏最常被虚填
   - 完成标准: 两个问题都有具体答案

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 信息已充分、卡在价值取舍的决策 — 审计只会拖延，该权衡就权衡
- 可逆的小决策 — 补信息的成本超过决策本身，直接试错更快
- 用审计当拖延借口 — "还没了解够"循环三轮以上时，应指出这一点而不是继续开清单

### 作者在书中警告的失败模式

- **君之三患** (ce02): 信息与决策权分离 — 不掌握一线信息的人下指令（"縻军"）。对个人的映射：用二手转述代替一手了解就做决定

### 作者的盲点 / 时代局限

- "知彼"被默认可达成；对方可能主动欺骗（反情报），本篇未展开——两栏审计要对"信息来源可靠性"多问一层
- 象限-胜率的对应是经验断言不是统计结论，"知彼知己"降低的是风险，不是保证"百战不殆"的胜率承诺

### 容易混淆的邻近方法论

- "上下同欲者胜"（本篇被淘汰的候选）— 那是组织对齐问题；信息审计不解决"想不想"，只解决"知不知"
- "多做调研" — 泛泛调研没有两栏结构，最容易漏掉的恰恰是知己栏
