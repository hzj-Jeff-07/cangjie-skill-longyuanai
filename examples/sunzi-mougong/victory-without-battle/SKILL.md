# 伐谋阶梯 — 不战而胜的手段排序

## R — 原文 (Reading)

> "上兵伐谋，其次伐交，其次伐兵，其下攻城。攻城之法，为不得已。……故善用兵者，屈人之兵而非战也，拔人之城而非攻也。"
>
> — 孙武，《孙子兵法·谋攻篇》

---

## I — 方法论骨架 (Interpretation)

面对冲突，手段不是一个池子而是一条阶梯，按破坏成本从低到高排列：

1. **伐谋** — 让对方的计划失去成立条件（对方的方案不成立，冲突就不必发生）
2. **伐交** — 改变力量结构：瓦解对方的联盟、争取关键第三方
3. **伐兵** — 正面消耗战
4. **攻城** — 对对方最坚固处的强攻，成本最高

规则只有两条：永远从阶梯低端开始尝试；只有确认低端手段不可行才升级。最高破坏手段不是禁区，但必须是"不得已"，不能是默认或情绪出口。背后的价值标准是"全胜"：打烂了赢，赢来的东西也贬值了，破坏本身是你的成本。

## A1 — 书中的应用 (Past Application)

> 注: 谋攻篇无作者亲历案例（见 `candidates/cases.md`），以下为篇中给出的**反面警示情境**。

### 情境: 蚁附攻城
- **问题**: 攻城条件不具备（器械未成），但将领怒火中烧
- **违反方法论的做法**: 跳过整个阶梯，直接驱使士兵爬城强攻（"蚁附"）
- **结论**: "杀士三分之一而城不拔" — 付出最高成本，仍然失败
- **作者的判词**: "此攻之灾也" — 灾难来自手段选择，而非实力不足

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 被竞对/同事/对手"打了一下"，正在讨论怎么反击、报复
2. 商业竞争决策里默认了正面对抗（价格战、对标开撕、抢同一渠道）
3. 纠纷处理直接跳到了最高成本选项（起诉、公开举报、决裂）

### 语言信号 (用户的话里出现这些就应激活)

- "要不要跟他们打价格战 / 正面刚 / 硬碰硬"
- "我想报复 / 反击 / 给他点颜色看看"
- "准备起诉 / 撕破脸 / fight back / retaliate"

### 与相邻 skill 的区分

- 与 `strength-ratio-decision` 的区别: 本 skill 回答"选哪类手段"（谋/交/兵/城），它回答"实力比允许哪种动作"（围/攻/分/战/逃/避）。先用本 skill 选层级，若落到"伐兵"层再用它定打法
- 与 `know-both-sides` 的区别: 它是行动前的信息审计，不给手段建议；信息不完备时先用它

## E — 可执行步骤 (Execution)

1. **确认对抗结构**: 明确对方是谁、冲突的争夺物是什么
   - 完成标准: 能一句话说出"谁、为了什么、在对抗"
2. **从阶梯底端逐层生成选项**: 各写出至少 1 个"伐谋"（让对方计划失效）和"伐交"（改变联盟/第三方结构）选项
   - 完成标准: 低两层各有 ≥1 个具体可执行选项，或有明确证据证明该层无解
   - 判停条件: 若发现对己方实力/对方意图的信息不足以生成选项，先跳 know-both-sides
3. **评估升级必要性**: 只有低层选项全部被证伪，才允许进入"伐兵/攻城"层，并显式写出"不得已"的理由
   - 完成标准: 若选择高成本手段，存在一句能过审的"为什么低成本路径不可行"
4. **成本核算**: 对最终选项按"全胜"标准复核 — 赢了之后，争夺物还完整吗？
   - 完成标准: 能回答"赢下来的东西值多少、被这场对抗毁掉多少"

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无对抗方的纯执行/效率问题 — 没有"敌人"就没有阶梯
- 对方已发起不可逆的全面进攻、窗口以小时计 — 阶梯推演的前提是还有选择余地
- 日常人际小摩擦 — 把"伐谋"用在同事没回消息上是过度武装

### 作者在书中警告的失败模式

- **蚁附攻城** (ce01): 情绪替代成本计算，把最高成本手段当发泄出口。预警信号：决策理由从"划算"变成"咽不下这口气"

### 作者的盲点 / 时代局限

- 阶梯成本间距按冷兵器攻城设定；现代场景中"正面对抗"的成本可能远低于古代攻城，阶梯顺序要按实际成本重排，不能照抄
- 全篇是强势方视角；若你是绝对弱势方，"伐谋/伐交"的可行选项集可能很小，先用 strength-ratio-decision 确认处境
- 默认对方可被谋略/谈判影响；面对不可谈判的对手，阶梯可能直接塌缩到高层

### 容易混淆的邻近方法论

- "以和为贵/能忍则忍" — 那是回避冲突；本 skill 不回避冲突，只优化取胜手段的成本
